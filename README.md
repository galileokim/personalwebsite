# Galileo Kim

My personal website, built with React, TypeScript, Vite, and Tailwind CSS.

## Development

Use Node.js 24.

```sh
npm ci
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

Deploy the `dist/` directory to a static host.

## Content

Project descriptions and work experience live in `src/data/portfolio.ts`. Edit the page in `src/App.tsx` and styles in `src/styles.css`.
